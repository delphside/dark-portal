# Dark Portal

An analysis tool for the World of Warcraft auction house: it collects the
auction house data hourly and turns it into prices, volumes and crafting
margins. Application 2 of the Delphside programme, in design.

- The project: [#5](https://github.com/delphside/dark-portal/issues/5).
- Its records (artefacts, capacity plan, workstreams, profile) are in the
  programme repository, under
  [`applications/dark-portal/`](https://github.com/delphside/programme/tree/main/applications/dark-portal).
- `programme/` is the programme's submodule: its generic rules, skills and
  tooling. Run `git submodule update --init` after a clone.
- `app-profile.toml` is the technical profile the programme's tooling reads.
