# Data dictionary

What each column in [5.4.2](5.4.2-storage-schema.md) holds, by name. A column
carries the same meaning in every table it appears in.

> **Draft for #7's design.**

## Types

| Type | DuckDB | Rust | Holds |
| --- | --- | --- | --- |
| copper | `UBIGINT` | `Copper(u64)` | an amount of money: 1 gold is 100 silver is 10,000 copper |
| hour | `TIMESTAMPTZ`, on the hour, UTC | `Hour(i64)`, hours since the Unix epoch | the hour starting of a snapshot ([5.2.2](5.2.2-listing-lifecycle-and-events.md#times)) |
| item id | `UINTEGER` | `ItemId(u32)` | Blizzard's item id |
| auction id | `UBIGINT` | `AuctionId(u64)` | Blizzard's auction id, increasing between snapshots |
| time left | `ENUM ('SHORT', 'MEDIUM', 'LONG', 'VERY_LONG')` | `TimeLeft` | the band a listing's remaining time is in: under 30 minutes, 30 minutes to 2 hours, 2 to 12 hours, 12 to 48 hours |
| event kind | `ENUM ('posted', 'partly_sold', 'sold', 'unsold', 'expired', 'cancelled')` | `EventKind` | an event of [5.2.2](5.2.2-listing-lifecycle-and-events.md#the-events) |
| tier | `ENUM ('observed', 'certain', 'inferred')` | `Tier` | how sure an event or outcome is |
| rule | `ENUM ('EV-1', … 'EV-6')` | `Rule` | the rule that produced an event |

## Columns

| Column | Type | Holds |
| --- | --- | --- |
| `id` | auction id | the listing |
| `item` | item id | the commodity |
| `hour` | hour | the snapshot hour the row describes |
| `day` | `DATE`, UTC | the day the row summarises |
| `last_modified` | `TIMESTAMPTZ` | the snapshot's `last-modified` header |
| `fetched_at` | `TIMESTAMPTZ` | when the collector received the response |
| `quantity` | `UINTEGER` | units in the listing at that hour |
| `unit_price` | copper | the price of one unit |
| `time_left` | time left | the listing's band at that hour |
| `first_seen`, `last_seen` | hour | the first and latest snapshot showing the listing |
| `posted` | hour, or null | the hour the listing was posted; null where unknown |
| `position` | `UINTEGER` | the listing's place in its item's queue, the head being 1 |
| `units_ahead` | `UBIGINT` | units in listings ahead of it in the queue |
| `units_at_or_below` | `UBIGINT` | units listed at its price or lower |
| `lowest` | copper | the lowest unit price listed |
| `span` | `UTINYINT` | hours since the previous snapshot held: 1 unless one was missed |
| `units` | `UINTEGER` | units an event moved, or units at a price level |
| `listings` | `UINTEGER` | listings counted |
| `*_units` | `UBIGINT` | units in the named flow in that hour or day ([5.2.3](5.2.3-consumable-profiles.md#flows)) |
| `median_fill_price` | copper | the median of the day's hourly fill prices at `default_n` |
| `default_n` | `UINTEGER` | the day's default quantity for a fill price |
| `hours_held` | `UTINYINT` | the day's hours with a snapshot |
| `name`, `class`, `subclass` | `VARCHAR` | the item's name and Blizzard's item class, in British English |
| `vendor_sell_price` | copper | what a vendor pays for one |
| `vendor_buy_price` | copper, or null | what a vendor charges for one; null where no vendor sells it |
| `body` | `JSON` | Blizzard's item response, unchanged |
