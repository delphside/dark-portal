# Data dictionary

The types Dark Portal's data is held in, and what each column in
[5.4.2](5.4.2-storage-schema.md) holds, by name. A column carries the same
meaning in every table it appears in, except where its row gives two.

The code, `src/types.rs`, owns the Rust types; this table follows it.

## Types

A type with a fixed set of values is held as `VARCHAR` holding one of them,
since DuckLake has no `ENUM` type; `dp` writes no other value.

| Type | DuckDB | Rust | Holds |
| --- | --- | --- | --- |
| copper | `UBIGINT` | `Copper(u64)` | an amount of money: 1 gold is 100 silver, and 1 silver is 100 copper |
| hour | `TIMESTAMPTZ`, on the hour, UTC | `Hour(i64)`, hours since the Unix epoch | the hour starting of a snapshot ([5.2.2](5.2.2-listing-lifecycle-and-events.md#times)) |
| item ID | `UINTEGER` | `ItemId(u32)` | Blizzard's item ID |
| auction ID | `UBIGINT` | `AuctionId(u64)` | Blizzard's auction ID |
| time left | `VARCHAR`: `SHORT`, `MEDIUM`, `LONG`, `VERY_LONG` | `TimeLeft` | the band a listing's remaining time is in: under 30 minutes, 30 minutes to 2 hours, 2 to 12 hours or 12 to 48 hours |
| duration | `VARCHAR`: `12`, `24`, `48` | `Duration` | the hours a listing was posted for |
| event kind | `VARCHAR`: `posted`, `partly_sold`, `sold`, `expired`, `cancelled` | `EventKind` | an event ([5.2.2](5.2.2-listing-lifecycle-and-events.md#the-events)) |
| outcome | `VARCHAR`: `sold`, `expired`, `cancelled` | `Outcome` | how a listing ended |
| tier | `VARCHAR`: `observed`, `certain`, `inferred` | `Tier` | how sure a fact is ([5.2.2](5.2.2-listing-lifecycle-and-events.md#how-sure-a-fact-is)) |
| rule | `VARCHAR`: `EV-1`, `EV-2`, `EV-3`, `EV-5`, `EV-6` | `Rule` | the rule that decided an event's kind |
| market | `VARCHAR`: `eu-commodities` | `Market` | the auction house a snapshot is of |

```rust
pub struct Copper(pub u64);
pub struct ItemId(pub u32);
pub struct AuctionId(pub u64);
pub struct Hour(pub i64);

pub enum TimeLeft { Short, Medium, Long, VeryLong }
pub enum Duration { H12, H24, H48 }
pub enum EventKind { Posted, PartlySold, Sold, Expired, Cancelled }
pub enum Outcome { Sold, Expired, Cancelled }
pub enum Tier { Observed, Certain, Inferred }
pub enum Rule { Ev1, Ev2, Ev3, Ev5, Ev6 }
pub enum Market { EuCommodities }

/// One listing as a snapshot shows it: the listing columns of a bronze row.
pub struct Listing {
    pub id: AuctionId,
    pub item: ItemId,
    pub unit_price: Copper,
    pub quantity: u32,
    pub time_left: TimeLeft,
}

/// An `event` row.
pub struct Event {
    pub hour: Hour,
    pub id: AuctionId,
    pub item: ItemId,
    pub kind: EventKind,
    pub units: u32,
    pub unit_price: Copper,
    pub tier: Tier,
    pub rule: Rule,
    pub tie: bool,
    pub span: u16,
}

/// The queue around one listing at one hour.
pub struct QueuePlace {
    pub lowest: Copper,
    pub position: u32,
    pub units_ahead: u64,
    pub units_at_or_below: u64,
}

/// A `listing_record` row: `posting` and `end` flatten to `posting_*` and
/// `end_*` columns.
pub struct ListingRecord {
    pub id: AuctionId,
    pub item: ItemId,
    pub unit_price: Copper,
    pub quantity: u32,
    pub first_seen: Hour,
    pub last_seen: Hour,
    pub posted: Option<Hour>,
    pub duration: Option<Duration>,
    pub posting: Option<QueuePlace>,
    pub ended: Hour,
    pub outcome: Outcome,
    pub outcome_tier: Tier,
    pub tie: bool,
    pub units_sold: u32,
    pub end: QueuePlace,
    pub end_units_undercut: u64,
}
```

## Columns

| Column | Type | Holds |
| --- | --- | --- |
| `id` | auction ID | the listing |
| `item` | item ID | the commodity |
| `market` | market | the auction house |
| `hour` | hour | the snapshot hour the row describes |
| `day` | `DATE`, UTC | the day the row summarises |
| `last_modified` | `TIMESTAMPTZ` | the snapshot's `last-modified` header |
| `fetched_at` | `TIMESTAMPTZ` | when `dp` received the response |
| `status` | `USMALLINT` | the HTTP status of Blizzard's item response: 200 or 404 |
| `body` | `JSON`, or null | Blizzard's item response, unchanged; null for a 404 |
| `bronze_file` | `VARCHAR` | the bronze file an hour was processed from, relative to the data folder |
| `committed_at`, `found_at` | `TIMESTAMPTZ` | when an hour was committed, or found missing |
| `quantity` | `UINTEGER` | units in the listing at that hour; in `listing_record`, when first seen |
| `unit_price` | copper | the price of one unit |
| `time_left` | time left | the listing's band at that hour |
| `first_seen`, `last_seen` | hour | the first and latest snapshot showing the listing |
| `posted` | hour, or null | the hour the listing was posted; null for a listing in the first snapshot collected or first seen after a gap |
| `duration` | duration, or null | the listing's duration, from its lifetime; null unless it expired, or where its posting hour is unknown |
| `position` | `UINTEGER` | the listing's place in its item's queue, the head being 1 |
| `units_ahead` | `UBIGINT` | units in listings ahead of it in the queue |
| `units_at_or_below` | `UBIGINT` | units listed at its price or lower |
| `lowest` | copper, or null | the lowest unit price listed; null where nothing is listed |
| `posting_*` | as the column it prefixes | the queue around a listing in the hour it was first seen, where `posted` is known |
| `end_*` | as the column it prefixes | the queue around a listing in the last hour it was seen |
| `end_units_undercut` | `UBIGINT` | units in listings with a higher ID at a lower price, still listed when it was last seen |
| `ended` | hour | the hour the listing was first missing |
| `kind` | event kind | what happened |
| `units` | `UINTEGER` | in `event`, units the event moved; in `price_level_hour`, units listed at the price |
| `tier`, `outcome_tier` | tier | how sure the event's kind, or the outcome, is |
| `rule` | rule | the rule that decided the kind |
| `tie` | `BOOLEAN` | true where EV-4's tie applies: the unsold call rests on ID order within one snapshot |
| `outcome` | outcome | how the listing ended |
| `units_sold` | `UINTEGER` | units sold from the listing over its life: every drop in its quantity, and, where it sold, the quantity it then held; after a rise it can exceed `quantity` |
| `span` | `USMALLINT`, or null | hours since the previous snapshot held: 1 unless one was missed; null for the first hour collected, which has no previous one |
| `listings` | `UINTEGER` | listings counted |
| `units_listed` | `UBIGINT` | units listed at the hour |
| `posted_units`, `sold_floor_units`, `sold_estimate_units`, `expired_units`, `cancelled_units` | `UBIGINT`, or null | units in that flow in the hour or day ([5.2.3](5.2.3-consumable-profiles.md#flows)); null for the first hour collected; a day sums its hours that are not null |
| `median_fill_price` | `DECIMAL(18, 2)` in copper, or null | the median of the day's hourly fill prices at `default_n`, over the hours with any listed; null where none had |
| `default_n` | `UINTEGER` | the default *N* at 00:00 that day |
| `hours_held` | `UTINYINT` | the day's hours with a snapshot |
| `name`, `class`, `subclass` | `VARCHAR`, or null | the item's name and Blizzard's item class and subclass, in British English; null where the body lacks them |
| `vendor_sell_price` | copper | what a vendor pays for one; 0 where Blizzard's body gives none |
| `vendor_buy_price` | copper, or null | Blizzard's `purchase_price`: what a vendor charges for one, where a vendor sells it; null where Blizzard gives none or 0 |
