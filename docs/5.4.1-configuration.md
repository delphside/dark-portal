# Configuration

Every setting Dark Portal has. Deployment settings are environment variables
in each environment's `.env`; product settings are constants in one code
module per area
([1.10](https://github.com/delphside/programme/blob/main/docs/1.10-development-standards.md#where-an-applications-settings-are-held)).

> **Draft for #7's design.** Measured sources are in the capacity plan
> [`DP_CP_2026_10`](https://github.com/delphside/programme/blob/main/applications/dark-portal/3.2.3-capacity-plan/DP_CP_2026_10.md);
> the rest are reviewed once collection runs.

## Deployment settings

| Variable | Holds |
| --- | --- |
| `DP_ENV` | the environment's name, from the list in #11 |
| `DP_DATA_DIR` | the environment's data folder, such as `/srv/dp/prod` |
| `DP_BLIZZARD_CLIENT_ID` | the Blizzard client's ID |
| `DP_BLIZZARD_CLIENT_SECRET_FILE` | a file holding the client's secret, readable by the environment's user only |
| `DP_BUCKET` | the Object Storage bucket bronze is pushed to, or empty for none |
| `DP_LOCK_FILE` | the VM-wide lock every scheduled job takes |
| `DP_ADHOC_MEMORY_LIMIT` | DuckDB's `memory_limit` for an ad hoc query: 4 GB in production, 8 GB outside it |
| `DP_ADHOC_THREADS` | DuckDB's `threads` for an ad hoc query: 1, or 2 outside production for scans of silver alone |
| `DP_CONTAINER_MEMORY` | the container's memory limit |

## Product settings

| Setting | Value | Area | Source |
| --- | --- | --- | --- |
| region and namespace | EU, `dynamic-eu` | collection | the scope |
| item data namespace and locale | `static-eu`, `en_GB` | collection | Blizzard's API |
| hourly timer start | :35 past each hour | collection | Blizzard's refresh at about :31:40 |
| poll interval | 2 minutes | collection | chosen |
| retry window | until :25 past the next hour | collection | chosen: before the next run |
| retry backoff | 30 s, doubling to 5 min | collection | chosen |
| HTTP timeout | 60 s for a snapshot, 10 s otherwise | collection | chosen |
| token margin | 1 hour | collection | chosen |
| item fetch rate | 50 a second | collection | half Blizzard's limit |
| lock wait | 10 minutes, then exit `75` | scheduling | chosen |
| daily timer start | 00:50 UTC | scheduling | between hourly runs |
| hourly job DuckDB `memory_limit` | 1 GB | transform | `DP_CP_2026_10` |
| hourly job DuckDB `threads` | 1 | transform | `DP_CP_2026_10` |
| default *N* window | 7 days | profiles | chosen |
| turnover window | 24 hours | profiles | chosen |
| depth ladder cut-off | 48 hours of depth | profiles | chosen: the longest duration |
| hourly keep | 4 weeks | storage | R2 |
| daily keep | indefinitely | storage | R2 |
| silver keep | indefinitely, until #5 sets one | storage | #5 |
| bronze keep on the host | 7 days | storage | #5 |
| bronze keep in the bucket | 1 year, by the bucket's lifecycle rule | storage | #5 |
